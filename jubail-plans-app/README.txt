تطبيق خطط التحسين والتطوير – مدارس الجبيل الأهلية (تطبيق ويب قابل للتثبيت PWA)
==========================================================================
الملفات: index.html (التطبيق) · manifest.webmanifest · sw.js (العمل دون إنترنت) · الأيقونات

1) النشر (مرة واحدة)
- ارفع كل محتويات هذا المجلد كما هي إلى أي استضافة تدعم https (مثل مساحة موقع المدارس، أو GitHub Pages، أو Netlify، أو Cloudflare Pages).
- ملاحظة: التثبيت كتطبيق لا يعمل من ملف على الجهاز (file://) بل من رابط https.

2) التثبيت على الأجهزة (يفتح كل مستخدم الرابط)
- Windows / Mac: Edge أو Chrome ← أيقونة التثبيت في شريط العنوان ← تثبيت.
- Android: Chrome ← القائمة ⋮ ← تثبيت التطبيق.
- iPhone / iPad: Safari ← زر المشاركة ← إضافة إلى الشاشة الرئيسية.

3) أول تشغيل
- يظهر «إعداد أولي»: يعيّن المشرف العام (سفر بن حسن الزهراني) رمزه، ثم من «👥 المستخدمون» يعيّن رمزًا لكل من: يحيى العلكمي، إيهاب عطا أبو السعود، منصور البارقي، عبدالله القيسي، عبدالعزيز الزهراني.

4) الصلاحيات
- المشرف العام: تعديل كل المراحل + إدارة المستخدمين + استيراد + استعادة الأصل.
- المشرف الأكاديمي: تعديل كل المراحل + تصدير.
- منسق التقويم: تعديل كل المراحل + تصدير واستيراد.
- وكيل كل مرحلة: تعديل مرحلته فقط وعرض البقية.

5) حدود يجب معرفتها
- البيانات محفوظة على كل جهاز على حدة. لنقل التعديلات بين الأجهزة: «📤 تصدير البيانات» ثم إرسال الملف (واتساب/بريد) ثم «📥 استيراد البيانات» عند المشرف العام أو المنسق (يُستبدل الأحدث فقط).
- رموز الدخول والصلاحيات تنظيمية داخل التطبيق وليست حماية أمنية صارمة (لا يوجد خادم). للمزامنة الفورية بين الجميع استخدم نسخة claude.ai المشتركة.
- نسيان رمز المشرف العام: لا يوجد استرجاع؛ يُمسح بيانات الموقع من المتصفح (وتضيع التعديلات غير المصدَّرة)، لذا صدّر نسخة احتياطية دوريًا.
- لإصدار المتاجر (Google Play / App Store / Microsoft Store) يلزم حساب مطوّر وتوقيع؛ يمكن تحويل هذا المجلد بعد نشره على https عبر pwabuilder.com إلى حزم Android وWindows وiOS.
